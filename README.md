# OneSpace — Modern Minimal Productivity Application

OneSpace is a premium, minimal, and calm digital workspace designed for high focus and effortless task management.

---

## 🚀 Quick Start

### 1. Local Hostname Setup
Ensure `127.0.0.1 onespace.local` is added to your Windows `hosts` file (`C:\Windows\System32\drivers\etc\hosts`).

### 2. Launch Development Mode
Run the following from the root directory:

```bash
# Start backend API (Port 5000)
npm start

# Start frontend dev server (Port 80)
npm run dev:onespace
```

Access the application in your browser at:
👉 **[http://onespace.local](http://onespace.local)**

---

## 📁 Project Structure

- `OneSpace_Phase1/` — Core application containing Express 5 API and React Vite frontend.
- `OneSpace_Phase1/src/` — React UI components, design tokens, and state logic.
- `OneSpace_Phase1/server/` — Express REST API controller logic and data stores.
